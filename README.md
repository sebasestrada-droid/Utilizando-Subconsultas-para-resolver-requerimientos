# Utilizando-Subconsultas-para-resolver-requerimientos
PRY2205 – Actividad Formativa Semana 5

Utilizando Subconsultas para Resolver Requerimientos

Descripción

Proyecto desarrollado en Oracle SQL para la empresa ficticia FinanCorp, enfocado en la gestión de clientes y productos financieros mediante consultas SQL.

Casos desarrollados

Caso 1: Listado de Clientes

- Identificación de trabajadores dependientes.
- Filtrado de profesionales contadores y vendedores.
- Cálculo del promedio de años de inscripción mediante subconsulta.
- Ordenamiento por RUT ascendente.

Caso 2: Aumento de Crédito

- Obtención del RUT, edad y cupo disponible de los clientes.
- Comparación del cupo disponible mediante una subconsulta.
- Creación y almacenamiento de resultados en "CLIENTES_CUPOS_COMPRA".
- Ordenamiento por edad ascendente.

Contenidos aplicados

- Consultas SQL y subconsultas.
- JOIN entre tablas.
- Funciones de caracteres y numéricas.
- Funciones de agrupación.
- Restricciones y ordenamiento de datos.
- Creación de tablas mediante "CREATE TABLE AS SELECT".

Requisitos

- Oracle Database.
- Oracle SQL Developer.
- Usuario de base de datos "PRY2205_S5".
- Tablas previamente creadas y pobladas.

Ejecución

1. Crear el usuario y la conexión correspondiente.
2. Ejecutar el script de creación y poblamiento de las tablas.
3. Abrir "PRY2205_Semana5_FinanCorp.sql".
4. Ejecutar el archivo mediante F5 en Oracle SQL Developer.
